# Expert Team

This directory contains the specialized expert profiles for the project team.
Each expert brings deep domain knowledge and works collaboratively on the x402-TON project.

## Team Structure

### Core Protocol Team
- **Protocol Architect** — x402 specification, protocol design, security model
- **Smart Contract Engineer** — Tact/FunC, TON VM, Jetton standards, testing

### Backend Team
- **Backend Systems Engineer** — Node.js, Express/Hono, WebSocket, facilitator server
- **Blockchain Integration Specialist** — TON SDK, RPC, transaction building, BoC serialization

### Frontend Team
- **Frontend Lead** — React 19, Vite, TypeScript, component architecture
- **UI/UX Designer-Developer** — Animations, Framer Motion, responsive design, Telegram theme integration
- **Telegram Mini App Specialist** — TMA SDK, TON Connect, bot integration, Mini App lifecycle

### AI & Agent Team
- **AI Agent Developer** — Tool use patterns, autonomous agent loops, wallet management

### Cross-cutting
- **DevOps & Deployment** — Vercel, Railway, CI/CD, testnet deployment
- **ENS Integration Specialist** — ENS resolution, cross-chain identity, payment UX with ENS names
