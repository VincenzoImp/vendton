# EPFL BSA Hackathon 2026 — Stablecoins & Payments on TON

Project plans for the AlphaTON Capital track at the [BSA Stablecoin & Payments Hackathon](https://hackathon.bsaepfl.ch/) (March 20-22, 2026, EPFL).

## Project Plans

### 1. [x402-TON](./01-x402-ton.md) — First x402 Protocol on TON ⭐ TOP PICK
Port Coinbase's x402 payment protocol to TON, enabling AI agents to pay for HTTP services with USDT via Telegram Mini App.

### 2. [StreamPay TON](./02-streampay-ton.md) — Real-Time Payment Streaming
First payment streaming protocol on TON. Smart contracts that send USDT second by second, with a live counter in a Telegram Mini App.

### 3. [PayAgent](./03-payagent-ton.md) — AI Agent Wallet Framework
Programmable wallets for AI agents on TON with on-chain spending controls (daily caps, whitelists, expiry), powered by Wallet V5 extensions.

## Track: AlphaTON Capital
- **Prize Pool**: $6,000 USD + 3,999 TON + Claude Max subscriptions
- **Focus**: TON blockchain, Telegram-native, AI agents, stablecoins & payments
- **Criteria**: Idea, execution, product-market fit
